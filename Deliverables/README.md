# Deliverables

Folders 1-7 contain the executed notebook and its EDA, modeling table, comparisons, experiments, explanations and inference exports. Folder `8- Report` contains the analytical and technical PDFs plus a guide explaining their different roles. Figures are embedded in those PDFs.

## Run the notebook

Use Python 3.12 (64-bit), install `requirements-tested.txt` into the chosen kernel environment, and open `1- Notebook/F1 Podium Prediction.ipynb`. Keep the complete 14-table `Dataset/` directory at the project root, beside Deliverables. Choose Restart Kernel and Run All; dataset discovery works automatically from the delivered notebook folder. A custom `F1_DATA_DIR` is optional.

The dataset is available from https://www.kaggle.com/datasets/rohanrao/formula-1-world-championship-1950-2020 . Raw CSVs are excluded from GitHub and must be attached on Kaggle or downloaded locally.

`links.txt` contains the published Kaggle notebook and GitHub repository URLs. Read the project-root README for installation commands, methods, inference usage and the reused-test evaluation limitation.
